Runtime licenses and source

The browser runtime

This launcher distributes a modified OpenJDK 25 runtime, browser adapters and open-source support libraries. The reviewed runtime archive excludes Minecraft client/server code and game assets. Your browser downloads the game client and required libraries from Mojang. Sounds and panorama images use direct browser requests to Mojang first, then a version-pinned GitHub raw-file fallback with size and hash checks.

OpenJDK files retain GPL version 2 and the applicable Classpath or assembly exceptions identified in their source. The Classpath exception does not relicense OpenJDK or every JIT file under GPL version 3. Project-authored launcher and adapter code uses GPL version 3. Other dependencies retain their respective licenses.

The selected libjvm.so has SHA-256 {{RUNTIME_SHA256}}. These notices accompany that runtime distribution.

Corresponding source and build instructions

Download the source and build instructions. The archive contains the runtime adapters, custom OpenJDK and libffi patches, build scripts, dependency pins, source provenance and licenses for this distribution. It excludes game files, account credentials, player data and generated build caches.

The selected runtime source-tree SHA-256 is {{SOURCE_TREE_SHA256}}. The source manifest identifies the archive checksum, runtime identity, upstream revisions and custom patches. Follow docs/runtime-build.md in the archive to rebuild the runtime from the pinned upstream sources and included patches.

The source repository includes the Docker installation and development instructions. Use the manifest and source archive to identify the source accompanying this host's runtime.
